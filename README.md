## Como Jogar
1. Clique em duas cartas no tabuleiro para virá-las.
2. Combine cada **termo/sigla** ao seu **conceito ou importância** correspondente.
3. Ao acertar um par, as cartas permanecem abertas e uma breve explicação sobre o componente é exibida acima do tabuleiro.
4. Use o botão **Reiniciar** a qualquer momento para embaralhar as cartas e iniciar uma nova partida.
5. Vence aquele com menor quantidade de tentativas!

## Termos e Conceitos Utilizados
1. **CPU** — Cérebro do computador que interpreta e executa instruções.
2. **ULA** — Parte do processador que faz cálculos e operações lógicas.
3. **UC** — Gerencia o fluxo de dados e busca instruções na memória.
4. **REGISTRADORES** — Memória ultrarrápida interna ao processador para dados imediatos.
5. **RAM** — Memória principal volátil usada pelos programas em execução.
6. **ROM** — Memória não volátil gravada de fábrica para inicialização.
7. **CACHE** — Memória intermediária veloz que reduz acessos à memória principal.
8. **MEMORIADEMASSA** — Armazenamento permanente de grande capacidade para arquivos e sistema.
9. **DMA** — Permite periféricos transferirem dados sem sobrecarregar o processador.
10. **ADDRESSBUS** — Via unidirecional que indica onde ler ou gravar dados.
11. **DATABUS** — Via bidirecional que transporta informações entre componentes.
12. **MICROCONTROLADOR** — Chip único com processador, memória e periféricos integrados.
