# Memória de Arquitetura Computacional

Jogo da memória interativo desenvolvido em HTML, CSS e JavaScript puros para fixação dos conceitos fundamentais de Arquitetura Computacional.

## Link do Site Publicado
https://nicolasmussinhati.github.io/Ativ-Avaliativa-ArqComp/

## Como Jogar
1. Selecione a dificuldade desejada no menu superior (Fácil com 8 pares, Médio com 12 pares ou Difícil com 16 pares).
2. Clique em duas cartas no tabuleiro para virá-las e encontrar os pares correspondentes entre **termo/sigla** e **conceito/importância**.
3. Ao acertar um par, as cartas ganham um efeito visual de acerto, uma breve explicação é expandida na tela e o termo é automaticamente adicionado ao **Menu Lateral de Conceitos Desbloqueados**.
4. Se errar, as cartas tremem (efeito *shake*) em tom avermelhado antes de desvirarem.
5. A qualquer momento, clique em qualquer termo já descoberto no menu lateral para rever a sua explicação detalhada.
6. Ao completar todos os pares do nível, um sumário de desempenho é exibido com o total de tentativas, taxa de aproveitamento e dicas personalizadas de estudo.
7. Use o botão **Reiniciar** ou **Jogar Novamente** para embaralhar as cartas e iniciar uma nova partida.

## Termos e Conceitos Utilizados
1. **CPU** — Cérebro do computador que interpreta e executa instruções.
2. **ULA** — Parte do processador que faz cálculos e operações lógicas.
3. **UC** — Gerencia o fluxo de dados e busca instruções na memória.
4. **REGISTRADORES** — Memória ultrarrápida interna ao processador para dados imediatos.
5. **RAM** — Memória principal volátil usada pelos programas em execução.
6. **ROM** — Memória não volátil gravada de fábrica para inicialização.
7. **EEPROM** — Memória não volátil apagável e regravável eletricamente.
8. **FLASH** — Memória não volátil regravada em blocos para armazenamento.
9. **CACHE** — Memória intermediária veloz que reduz acessos à memória principal.
10. **MEMORIADEMASSA** — Armazenamento permanente de grande capacidade para arquivos e sistema.
11. **DMA** — Permite periféricos transferirem dados sem sobrecarregar o processador.
12. **ADDRESSBUS** — Via unidirecional que indica onde ler ou gravar dados.
13. **DATABUS** — Via bidirecional que transporta informações entre componentes.
14. **MICROCONTROLADOR** — Chip único com processador, memória e periféricos integrados.
15. **DUALCORE** — Processador com dois núcleos de execução no mesmo chip.
16. **QUADCORE** — Processador com quatro núcleos de execução integrados.
